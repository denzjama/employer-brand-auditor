# Demo prompt

The demo run sent exactly this prompt, followed by two line breaks and the full, unchanged contents of `demo-company-materials.md`:

```text
Run a full employer brand audit of the materials below. They are our current candidate-facing materials.
```

You can reproduce the demo by pasting the same prompt and the contents of `demo-company-materials.md` into a session where Employer Brand Auditor is loaded. Your output will not be word-for-word identical, because model outputs vary between runs. It should follow the same structure and reach a broadly similar diagnosis.
